# L3-5: preregistered performance conclusions

The versioned `riscv2x86.microarchitecture-experiment-contract.v5` contains a `riscv2x86.l3-statistical-experiment.v1` declaration. Its L3 report v4 contains each platform's original paired observations, not a precomputed pass flag. Older L3 contracts and the earlier `MetricContract` remain available, but only v5 makes the preregistered conclusion and sampling boundary below.

Each declared metric has a baseline and treatment label (shared by the experiment), a **within-platform** source and target metric name and physical unit, a finite valid range, difference or relative-to-baseline normalization, an explicit plain-language conclusion, direction (`increase`, `decrease`, `equivalent`, `noninferior`), minimum meaningful effect and margins. Source cycle and target cycle counts are never directly compared. Equivalence needs a positive margin; a nonsignificant comparison is not equivalence.

The contract fixes the program and proof identity, exact round count, minimum retained rounds, paired measurements per round, warmups per round, randomized presentation seed, noise threshold, whole-round exclusion rule, confidence level, number of bootstrap draws, Bonferroni correction, and per-platform environment, compiler and binary identities. The outer execution contract must agree on round count, seed, warmups, calibration and noise policy. Each report includes every planned round in its original order, paired values, noise score and whether the prespecified rule excludes it. Missing pairs, undeclared exclusions, changed randomization order or samples outside the declared range invalidate the report and yield `inconclusive`.

For each retained round, pairs are reduced to their average within-round effect. The seeded percentile bootstrap resamples **rounds**, not individual measurements, and produces a per-platform interval; with multiple metrics, the familywise confidence level is corrected by Bonferroni. The raw round effects, interval, effect, excluded round IDs, effective independent round count, units and correction appear in the versioned evidence and can be recomputed. Claims are restricted to the named program and controlled experimental conditions; the code does not establish that round independence or a reporter's noise score is trustworthy without a properly instrumented provider.

A source conclusion that cannot be established is `inconclusive` for the entire cross-platform preservation question. Once the source conclusion is reproduced, a target interval wholly supporting the contrary of its declared direction or lying outside a declared equivalence/noninferiority margin yields `failed`; a target interval crossing zero or a prespecified bound yields `inconclusive`. Both platforms supporting the preregistered conclusion yield `verified` **for that bounded within-platform conclusion only**. Statistical results are deduplicated per `(programId, experimentIdentity)` in batch output; correlated measurements from one program are never counted as independent programs. Hardware equivalence and cross-ISA absolute-counter equality are explicitly excluded.

Regression tests use synthetic report producers to exercise noise, missing measurements, source non-reproduction, reversed target trend, equivalence uncertainty, identity mismatches, multiple-metric correction and program-level deduplication. Actual L3 statistical verification requires independent source and target report producers and matched controlled hardware/compiler environments; none is asserted by the synthetic tests.
